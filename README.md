# ⚡ VS Electrical Online Store

A modern and responsive **Electrical Products E-Commerce Website** built to provide customers with an easy and convenient way to explore electrical products and services online.

The project is designed for **VS Electrical / Vinod Enterprises**, focusing on showcasing electrical products in a professional online store environment.

---

## 📌 Project Overview

**VS Electrical Online Store** is a web-based platform where users can browse electrical products and explore different product categories through a modern and responsive interface.

The goal of this project is to provide a digital platform for an electrical business that supports both **wholesale and retail customers**.

## 🚀 Getting Started

Follow the steps below to run this project on your local machine.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Diveshsingh169/VS-Electrical-online-store.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd VS-Electrical-online-store
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Configure Environment Variables

Create a `.env.local` file based on the provided example file:

```bash
.env.local.example
```

Add the required environment variables according to your project configuration.

### 5️⃣ Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
